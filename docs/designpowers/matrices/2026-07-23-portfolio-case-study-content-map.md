## Content retention and consolidation

- Grove’s existing flagship page remains the visual reference and live implementation; its Spanish fallback and canonical route were restored.
- MSK’s workflow, recreated dashboard, system map, certification/onboarding history, evidence, attribution qualifiers, external proof, and reflections are retained. Repeated operational context was consolidated into the systems chapter.
- Mobbin’s three source apps, 200+ captures, four-month scope, taxonomy lesson, app comparisons, and NDA-safe ownership boundary are retained. Repetitive capture descriptions were consolidated into one method and one entry-anatomy chapter.
- No confidential source files, patient data, invented metrics, or product-ownership claims were added.
- Spanish pages intentionally continue to use the existing condensed case-study content instead of unreviewed new translations.

## Implementation note

The shared layer uses progress, chapters, decision, evidence, screen-sequence, completion, reveal, and semantic theme primitives. Hero and comparison markup remain page-local because their artifacts and narrative structures are meaningfully different; extracting them would add configuration without reducing risk.
