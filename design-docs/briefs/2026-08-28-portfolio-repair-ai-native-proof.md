# Portfolio repair: AI-native proof without title drift

## Problem

The supervised recruiter audit is Conditional for a small set of high-impact reliability gaps: the mobile first viewport does not reliably expose a work action, the direct healthcare recruiter route lacks its own HTTP 200 shell, the targeted healthcare résumé is not tagged, and the research claims need durable evidence records. The current source already presents three primary studies and keeps Mobbin as supporting practice; that hierarchy should be preserved, not rebuilt.

The practitioner article “How to become an AI Designer” adds one useful direction: prove that design decisions survive into a working product. It does not provide job-market evidence for changing the primary title or adding résumé keywords.

## Audience

- Healthcare product-design recruiters making a six-second mobile scan.
- Hiring managers looking for research-to-decision traceability and implementation judgment.
- Readers using direct recruiter links, PDF extraction, keyboard navigation, or assistive technology.

## Chosen direction

Keep “Healthcare Product Designer” as the primary positioning. Use Grove as the supporting AI-native proof: a working React prototype, AI-assisted implementation, human-owned research/scope/accessibility/QA, and explicit confidence, provenance, override, and verification boundaries.

Rejected for this round:

- Rename the primary position to “AI Designer.” This dilutes the stronger healthcare thesis and is not supported by job-description evidence.
- Add a separate AI portfolio page. Grove can carry the proof without adding another route or recruiter decision.
- Rebuild the work hierarchy. The source already has MSK, Medical Logistics, and Grove as the three primary cases, with Mobbin visibly secondary.

## Success evidence

- At 390 × 844, an explicit “Review the MSK workflow” action is visible in the first viewport and remains at least 44px tall.
- Desktop retains the existing hero action; mobile does not repeat it in the text block.
- Grove states that the prototype is React and AI-assisted without calling it shipped or presenting AI output as evidence.
- `/curated/healthcare-product-service-designer/` receives a static 200 shell, `noindex, nofollow`, stays blocked by `robots.txt`, and remains absent from `sitemap.xml`.
- The targeted healthcare résumé remains one page with extractable text, working links, and a tagged structure tree.
- Grove and MSK have complete Portfolio Research Evidence Records; unknown participant counts, missing task records, and contribution boundaries stay explicit.

## Constraints and exclusions

- Reuse the Riso system and existing components; no new dependency or visual redesign.
- No deploy, commit, push, application, outreach, analytics mutation, or profile edit.
- No résumé keyword changes based only on a practitioner article.
- No claim that Grove is shipped or that AI replaced research, taste, judgment, or verification.
