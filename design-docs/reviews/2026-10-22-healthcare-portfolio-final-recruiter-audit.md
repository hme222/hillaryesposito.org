## What to do now

### Now

- Stop default portfolio recutting.
- Use MSK as the lead link for healthcare workflow, clinical systems, operations-platform, and internal-tool roles.
- Use the 90-second tour when a recruiter needs a fast cross-project scan; use the direct case link when the role maps clearly to one case.
- Pair each application with the healthcare-product résumé and a short outreach note naming the employer's specific workflow problem.

### Next

- Run 3–5 real 60–90 second recruiter or hiring-manager scans. Measure role recall, first case chosen, decision/status recall, and whether résumé/contact is found without coaching.
- Run one representative screen-reader session and one 200% browser-zoom session on the production URL.
- Use feedback only when it repeats or blocks the hiring task; do not reopen the whole visual system for one taste preference.

### Later

- Revisit the broader Riso mono-label, hairline, and numbering language only as a system-level art-direction project. It is outside the healthcare recut and did not block the blind anti-AI or recruiter gates.

## Stop rule

Do not add another case study or resume broad polishing because an application is pending. Reopen the portfolio only for a verified broken path, a truthful new outcome, repeated recruiter confusion, or a role-specific evidence gap that the current primary/supporting set cannot answer.
