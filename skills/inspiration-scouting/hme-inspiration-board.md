# Inspiration Board — Hillary's Portfolio

Persistent board for the `inspiration-scout`. Each entry: what it is, the one
transferable lesson, and the leverage verdict for *this* portfolio (warm-editorial,
quiet authority, healthcare + responsible-AI, anti-AI-tell). Captured 2026-07-17
from a 3-agent Fable panel (inspiration-scout, design-lead, design-strategist).
Filter every reference through: does it strengthen *judgment*, *systems maturity*,
or *builder credibility* — the three signals a senior AI-healthcare hire is scanning for?

## Synthesized moves, sequenced

**Substance first (closes the audit gaps), then packaging:**

1. **Ship the anti-ai-auditor + ShowKit publicly**, each with a 3-paragraph "why I built this" (problem · judgment encoded · one honest limitation). Submit to Superpowered Design. → closes *under-shows-tooling* + *shipped-not-conceptual*; converts responsible-AI judgment into working software.
2. **One-page responsible-AI manifesto** — 3–5 dry, testable, project-backed principles. → closes *no-cross-project-POV*; becomes the spine linking military + MSK + AI.
3. **Package with taste, then distribute:** Overtone-grade art-direction consistency on case imagery; Dia demo-first opener on Grove; Mist bar on every section; ship the OG card; submit to Recent.

**The named trap:** aesthetic drift. A hero polish is a multiplier on substance, and a multiplier on unproven substance is zero. Every visual hour must answer: which hiring signal does this strengthen?

**Fast wins (leverage-per-hour):** the 1200×630 OG card; the Deck-Gallery headline pass; retiring the AI-tell decorations (blurred orbs, gradient overload) the design-lead flagged.
